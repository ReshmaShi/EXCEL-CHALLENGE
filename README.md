# Excel Data Cleaning and Preparation Project

Project Overview

This project demonstrates data cleaning and preprocessing techniques using Microsoft Excel. The dataset contains product-related information and was cleaned to improve data quality, consistency, and readiness for analysis.

 Objective

To clean and prepare a raw dataset by handling missing values, correcting inconsistencies, removing duplicates, transforming columns, applying number formatting, and using conditional formatting techniques.

 Dataset Attributes

* Product ID
* Product Name
* Brand Name
* Quantity
* Category
* Price

 Tasks Performed
 1. Handling Missing Values

* Checked for missing values in the Price column.
* Handled missing price information appropriately.
* Identified missing values in the Category column.
* Replaced missing categories with "Unknown" to maintain data completeness.

 2. Correcting Inconsistent Data

* Identified inconsistent text formats in the Product Name column.
* Corrected typos and misspellings in the Category column.
* Standardized text formatting using Excel's Find and Replace feature.
 3. Removing Duplicates

* Identified duplicate records based on all columns.
* Removed duplicate rows to improve data accuracy.
 4. Splitting and Merging Data

* Split the Product ID column into:

  * Manufacturing Date
  * Country Code
* Removed unnecessary characters where required.
* Merged Brand Name and Product Name into a new column called Product Brand.

 5. Number Formatting

* Formatted the Price column as Currency.
* Formatted the Manufacturing Date column in DD-MM-YYYY format.

 6. Conditional Formatting

* Applied Data Bars and Color Scales to the Price column.
* Created a custom conditional formatting rule to highlight cells where the Category is "Electronics".

 Tools Used

* Microsoft Excel
* Find and Replace
* Text to Columns
* Conditional Formatting
* Remove Duplicates
* Cell Formatting

# Outcome

The dataset was successfully cleaned, standardized, and transformed into an analysis-ready format. The project improved data accuracy, consistency, readability, and overall quality for further analytical tasks.
